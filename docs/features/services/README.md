# Services — Data & Business Logic

Centralized services for data management and operations.

Contains 7 service modules:
- Settings, search, shortcut, sync, and preview services
- Google Docs conversion utility
- Publishing service

| Service | Description |
| :--- | :--- |
| [**PREVIEW_SERVICE.md**](PREVIEW_SERVICE.md) | Đồng bộ hóa thời gian thực với cửa sổ Live Preview |
| [**PUBLISH_SERVICE.md**](PUBLISH_SERVICE.md) | Quản lý xuất bản tài liệu lên Cloudflare Worker |
| [**SETTINGS_SERVICE.md**](SETTINGS_SERVICE.md) | Quản lý cấu hình người dùng và AppState |
| [**SEARCH_SERVICE.md**](SEARCH_SERVICE.md) | Dịch vụ tìm kiếm nội dung và file toàn cục |
| [**SHORTCUT_SERVICE.md**](SHORTCUT_SERVICE.md) | "Bộ não" điều phối toàn bộ phím tắt trong ứng dụng |
| [**SYNC_SERVICE.md**](SYNC_SERVICE.md) | Đồng bộ hóa vị trí cuộn và con trỏ giữa các chế độ xem |
| [**MARKDOWN_LOGIC_SERVICE.md**](MARKDOWN_LOGIC_SERVICE.md) | Xử lý logic render Markdown và các tiện ích liên quan |
| [**GDOC_UTIL.md**](GDOC_UTIL.md) | Tiện ích chuyển đổi HTML sang định dạng Google Docs |
